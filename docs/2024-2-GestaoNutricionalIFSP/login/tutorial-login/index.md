# Tutorial: Efetuar Login

Este tutorial apresenta o passo a passo completo para efetuar login no Sistema de Gestão Nutricional (SGN) quando você deseja acessar sua conta.

* * *

## Como Fazer Login

### Passo 1: Acessar o Sistema

1.  Abra seu navegador web
2.  Digite o endereço do SGN
3.  Aguarde o carregamento da tela de login

[![Tela de Login do SGN](../../img/telalogin/telalogin.png)](../../img/telalogin/telalogin.png)

### Passo 2: Inserir Credenciais

1.  **Prontuário**: Digite seu número de prontuário no primeiro campo
2.  **Senha**: Digite sua senha no segundo campo
3.  **Opcional**: Marque "Mostrar Senha" se desejar visualizar os caracteres digitados

[![Tela de Login do SGN Preenchida](../../img/telalogin/telaloginpreenchida.png)](../../img/telalogin/telaloginpreenchida.png)

### Passo 3: Autenticação

1.  Clique no botão **"Entrar"**
2.  Aguarde a validação das credenciais
3.  Você será redirecionado para o dashboard principal

[![Tela de Login do SGN Preenchida](../../img/telalogin/telaloginpreenchidaentrar.png)](../../img/telalogin/telaloginpreenchidaentrar.png)
